# CryptoAX07 Development Roadmap

## Phase 1: Foundation & Core Mechanics (Completed)
- [x] **Interactive Simulations**: Seed phrase, Wallet transfers, Basic DeFi concepts.
- [x] **Gamification System**: XP, Badges, and progress tracking via LocalStorage.
- [x] **AI Guidance**: Gemini-powered chatbot for contextual help.
- [x] **Localization**: Support for English and Spanish.

## Phase 2: Enhanced Learning Experience (In Progress)
- [ ] **Smart Contract Security Sim**: Interactive game to identify malicious contract permissions.
- [ ] **Bridge Simulator**: Visualizing the movement of assets between Layer 1 and Layer 2.
- [ ] **Advanced Charting**: Adding technical analysis tools (RSI, MACD) to the Candlestick Sim.
- [ ] **Audio/Video Content**: Embedding short "Expert Tip" clips from the coaches within lessons.

## Phase 3: Platform Growth (Q3 2025)
- [ ] **User Accounts**: Cloud database integration to sync progress across devices.
- [ ] **NFT Certificates**: Minting soulbound tokens on a testnet upon course completion.
- [ ] **Community Hub**: A forum or discord integration for students to discuss simulations.
- [ ] **Live Market Data**: Real-time price feeds for the Portfolio Tracker simulation.

## Phase 4: Ecosystem Expansion (2026)
- [ ] **Mobile App**: Native iOS and Android application.
- [ ] **Coach Dashboard**: Allow coaches to view student progress and assign specific simulations.
- [ ] **Partnerships**: Integrations with verified wallets and exchanges for seamless onboarding.
